# Geek Services LLC Website Repo

This repository contains the starter website for Geek Services LLC.

## Structure

- `geek-services-site/` contains the static site files
- `netlify.toml` tells Netlify to publish the static site from that folder

## Netlify

This repo is set up so Netlify can deploy directly from the `main` branch using:

- publish directory: `geek-services-site`
- no build command required
