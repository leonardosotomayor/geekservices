# Founder Page Layout Recommendation

## Recommendation

Create a separate page for Leonardo Sotomayor rather than a homepage subsection.

Path recommendation:

- `/founder`

Navigation recommendation:

- add `Founder` to the main site navigation

## Why this is the best fit

The current site has a clear business goal: explain services and generate inquiries.

A founder page supports that goal by:

- adding credibility
- giving visitors a deeper trust layer
- keeping the main homepage focused on conversion

## Recommended Section Order

### 1. Hero

Include:

- name
- short identity line
- one paragraph summary
- buttons for resume and LinkedIn

### 2. Short Founder Story

Include:

- Yonkers background
- early interest in technology
- current focus on software, AI, and business applications

### 3. Focus Areas

Use 3-4 cards:

- Software Development
- Artificial Intelligence
- Technical Research
- Business Systems

### 4. Selected Work

Use project cards for:

- Context-Aware Language Learning Model
- Solar Panel Optimization
- Quantum Key Distribution study

Each card should show:

- title
- short summary
- what it demonstrates

### 5. Skills Snapshot

Use grouped lists:

- languages
- tools
- core concepts

### 6. Education and Recognition

Include:

- University at Albany
- Computer Science
- specialization in Mathematics and Finance
- intended minor in Accounting
- key awards

### 7. Resume and Connect

Use a simple CTA band:

- View Resume
- LinkedIn
- Contact

## Visual Direction

This page should feel slightly more personal than the services homepage, but still consistent with the site.

Recommended feel:

- cleaner and more editorial
- slightly less sales-oriented
- more emphasis on typography and structured content blocks

## Resume Recommendation

Do both:

- embed a visible resume link on the founder page
- keep the full PDF accessible as a standalone asset

Best implementation for now:

- `View Resume` opens PDF in a new tab
- `Download Resume` uses the same file as a direct download

## What not to include

- unrelated public job details
- exaggerated claims about expertise
- every school assignment
- vague motivational language

## Best Summary

The founder page should function as a trust page, not a second homepage and not a resume clone.
