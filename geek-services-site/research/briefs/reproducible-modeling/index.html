Making a Model Reproducible

A simulation is useful only when someone can understand what it assumes and how to repeat it. This note outlines a documentation method for analytical projects such as solar-panel configuration studies.

Record the experiment

State the question and output units. Save input sources, retrieval dates, software versions, and parameter choices. Separate measured inputs from assumed values. For a solar model, record location, tilt, azimuth, time interval, and weather-data source.

Compare and test sensitivity

Use a simple baseline before adding complexity. Change one input at a time and record how much the output changes. A difference between models may reflect different assumptions rather than a better design.

Publish enough to audit

Provide input definitions, execution steps, limitations, and clearly labeled plots. Do not describe simulated output as a field measurement. No new simulation or numerical finding is reported in this brief.
